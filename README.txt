This folder is for your image assets.

Suggested files to add later:
- favicon.ico          (small icon shown in browser tabs — referenced in every page's <head>)
- og-image.jpg         (1200x630px image shown when the homepage is shared on WhatsApp/social — referenced in index.html)
- logo.png / logo.svg  (only needed if you replace the text logo with a real logo image)

Until you add a favicon.ico, browsers will simply show no icon or a default one — this will not break the site.

The current homepage logo is a styled text logo ("TUTORIA") built with CSS, so you do not need an image to launch the site.
